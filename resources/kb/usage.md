# 智能客服

租户级的对外客服能力：学生在微信里提问，AI 先用知识库作答，答不上或遇到风险时转给老师人工接管。

## 它是怎么运作的

学生在**微信**里发起咨询（从小程序点客服入口，或扫客服码）。消息进到系统后：

1. AI 先接待 —— 用租户知识库检索并作答
2. 答不上来（连续几轮没命中知识库）或命中风险词 → **转人工**
3. 老师在企业微信客户端里接管，学生看到的还是同一个会话

学生全程用微信，**不需要加入企业微信**。老师侧用企业微信自带的客服工作台，无需另开系统。

## 前置条件

1. **企业微信已开通微信客服**，并把该客服账号配置为「可通过 API 管理」（企微管理后台 → 应用管理 → 微信客服）
2. **模块已启用**（本模块默认开启，租户可自行关闭）
3. **知识库已配置** —— 接入外部 KB 并上传常见问题内容；没配的话 AI 会说「没找到相关信息」并建议转人工

## 学生怎么找到客服

两种入口：

- **小程序里点按钮** —— 需小程序与该企微**同主体**（同一法人），在微信小程序管理后台绑定企微企业 ID 后，用 `wx.openCustomerServiceChat` 拉起
- **扫客服码 / 点客服链接** —— 适合贴在网页、公众号菜单、纸质材料上

## 老师在哪里接管

**企业微信客户端**里自带微信客服工作台，待接入的会话会出现在那里。老师不需要打开本系统的网页后台。

## 常见问题

**Q：学生说「AI 答非所问」怎么办？**
A：先看知识库有没有对应内容。AI 只依据知识库回答，不会编造；知识库没有的内容它答不出来是正常的。

**Q：AI 一直在回答，我想直接人工接管？**
A：在企业微信客服工作台里直接接管即可 —— 接管后 AI 会停止回复，不会插话。

**Q：AI 会不会答错重要问题？**
A：AI 的回复在发出前会过内容过滤（拦截内部标识与敏感信息）。涉及成绩、缴费等个人信息的问题，当前版本**一律不予回答**（需要先完成实名身份核验，尚未开放）。

**Q：转人工是自动的吗？**
A：是。用户主动要求、命中风险词、或连续几轮答不上来，都会自动转人工。

## 当前版本不支持的

- 学生自助查询个人信息（课表 / 成绩 / 缴费）—— 需先做实名核验，后续版本开放
- 网页与 APP 端接入（当前仅微信渠道）
- 多渠道统一收件箱（坐席侧用企微自带工作台）
